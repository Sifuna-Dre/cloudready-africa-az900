# CloudReady Africa ☁️

**An unofficial, beginner-friendly AZ-900 exam preparation tool built for the #1MillionDevs movement.**

## The Problem

Cloud beginners can memorize practice answers without understanding the concepts behind them. This makes revision frustrating and leaves learners unsure which topics need more attention.

## The Solution

CloudReady Africa is an interactive study prototype that helps learners practise original Azure Fundamentals questions, receive immediate explanations, filter questions by topic, and review their practice performance.

## Features

- Original multiple-choice practice questions
- Immediate feedback and explanations
- Topic filtering across the three AZ-900 skill areas
- Session score and topic-level progress indicators
- Responsive interface for desktop and mobile
- Beginner-friendly examples relevant to African learners

## Technology

- HTML
- CSS
- Vanilla JavaScript

The prototype runs in a modern browser without a backend or API key.

## Run Locally

1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. Choose a topic and start practising.

## Learning Alignment

The content is organized around the public AZ-900 skills outline:

1. Describe cloud concepts
2. Describe Azure architecture and services
3. Describe Azure management and governance

Official study guide: https://learn.microsoft.com/en-us/credentials/certifications/resources/study-guides/az-900

## Limitations and Future Work

This is an early prototype with a small question bank. Future versions could add spaced-repetition flashcards, persistent learner accounts, personalized study plans, more original questions, and optional local-language explanations.

The readiness indicators reflect performance on this practice set only. They do not guarantee readiness for, or success in, the official exam.
